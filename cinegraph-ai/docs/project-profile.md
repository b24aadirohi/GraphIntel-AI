# GraphIntel AI — project profile

## Repository description

Python data analytics and conversational AI platform using Django, Flask,
FastAPI, PostgreSQL, Neo4j, explainable ML, RAG, MCP, Docker and GitHub CI/CD.

## Portfolio description

GraphIntel AI is a data and AI engineering project that connects SQL catalog
management with graph intelligence, digital analytics and conversational GenAI.
Django administers PostgreSQL data and reliable change delivery; Neo4j supports
relationship traversal and indexed retrieval; FastAPI exposes typed analytics,
recommendation and RAG endpoints; and Flask provides interactive exploration,
source inspection and reporting. The reference dataset contains fictional films.

The project demonstrates Python programming, NLP text vectorization, classical
machine learning, prompt/context engineering, bounded LLM integration and MCP
tool development. Operational work includes authenticated access, distributed
rate limiting, retry/dead-letter recovery, backup/restore, health monitoring,
Docker images, Kubernetes manifests and GitHub CI/CD vulnerability gates.

## Suggested project bullets

- Developed a Python data and AI platform across Django, Flask and FastAPI,
  integrating PostgreSQL source data with a Neo4j knowledge graph through
  transactional, ordered change delivery and recoverable background processing.
- Implemented NLP retrieval, explainable TF-IDF/graph recommendations and
  conversational RAG with bounded context, inspectable sources, citation checks
  and an optional hosted LLM adapter; exposed discovery tools through MCP.
- Built digital analytics and graph visualizations with daily event aggregates
  and CSV exports suitable for Excel, Power BI and Tableau import.
- Added authentication, CSRF protection, Redis throttling, health/metrics,
  backup/restore and Docker/Kubernetes deployment configuration, supported by
  database integration tests and GitHub CI/CD image-scanning gates.
